# 更新日志

每个版本的简短说明。应用在更新后会显示一次新内容,也可以在
设置 > 关于 > 新功能 中再次查看。

## 1.1.6

- **地图上的小队宝箱。** 同样使用本应用的队友会显示在地图上,带着他们搜过的每个宝箱,每人一种颜色。点击一个即可看到是什么时候、第几个宝箱。为此,在线模式现在还会发送你每个宝箱的时间、种类和位置,也包括以前的比赛。可在 设置 > 在线 中关闭。
- **抽到了什么奖励。** 每周奖励和海盗商店通行权现在按名称显示,并附带时间和来源宝箱,比赛页面和赛后通知中都有;比赛列表新增“奖励”列。队友找到的奖励标记为“小队”,附近其他玩家获得的标记为“不是你”。Gizmo 显示为 Gizmo:回放没有记录是哪一个。
- **宝藏时刻。** 概览显示下一个或正在进行的宝藏时刻,附带倒计时和加成内容。开始前 15 分钟会收到通知,进行中游戏内叠加层会显示“宝藏时刻”。在宝藏时刻中搜刮的宝箱会按加成计入海盗商店通行权概率。每一项都可在 设置 > 常规 中关闭。

## 1.1.5

- **自动安装更新。** 有新版本时,应用会在 Fortnite 关闭后自动安装。可在下方或 设置 > 关于 中关闭。
- **新增 16 种语言。** Fortnite 中的所有语言:德语、西班牙语(西班牙和拉丁美洲)、法语、意大利语、波兰语、葡萄牙语(巴西)、土耳其语、印度尼西亚语、越南语、泰语、日语、韩语、中文(简体和繁体)和阿拉伯语。应用会以 Windows 的语言启动,可在 设置 > 常规 中切换。
- **全新设置。** 左侧是分类,每个选项都有开关,每次更改都会立即保存。
- **六种配色主题。** 默认仍是 Midnight;Graphite、Deep sea、Amethyst、OLED(纯黑)和浅色的 Parchment 在 设置 > 常规 中。
- **在 Discord 中显示宝箱。** Fortnite 运行时,你的 Discord 资料会显示总数、今天的宝箱和比赛计时,还有一个让好友获取应用的按钮。可在 设置 > OBS 和 Discord 中选择显示内容或关闭。
- **关于。** 版本、更新、帮助和开源许可证集中在一处。“复制应用信息”会把报告问题所需的内容复制到剪贴板。
- **可以更改对账号的回答。** 设置 > 计数 会列出在这台电脑上玩过的其他账号。误标为你的或不是你的账号可以改回来,其基数和奖品都会保留。
- 菜单中新增 **“在 GitHub 上点星”** 链接。

## 1.1.4

- **俄语界面。** 可在首次启动时或在 设置 > 常规 中选择语言。
- **一台电脑上的多个账号。** 每个 Epic 账号都有各自的总数,可在菜单中切换。出现新账号的回放时,应用会询问是否是你的账号。Epic 中的新名字会自动更新,不再需要输入名字。
- **悬浮窗上的比赛计时。** 在“比赛中”旁边显示比赛自加载以来进行了多久。
- **悬浮窗会藏到其他窗口后面。** 用 Alt+Tab 离开 Fortnite 它就会消失,回来时又会出现。可在 设置 > 悬浮窗 中关闭。
- **游戏结束后回到等待状态。** 应用随 Fortnite 启动时,会在 Fortnite 关闭一分钟后回到等待状态。
- **挖出的宝箱也会计入。** 挖出时已经是打开状态的埋藏宝箱现在会计入。更新后会重新统计一次你的比赛。
- 修复:从列表中移除的比赛重启后仍保持移除,网速慢时也能下载更新,设置中的复选框会立即生效。

## 1.1.3

- **排行榜。** 所有开启在线模式使用本应用的人,按宝箱、最佳比赛和比赛场数排名,可看全部时间、本周或今天。点击列可排序。在 设置 > 在线 中可以显示为 Anonymous 而不是你的名字。
- **随 Fortnite 启动。** 登录 Windows 后,应用会安静等待,Fortnite 启动时在托盘中打开。可在 设置 > 常规 中改回随 Windows 启动。
- **直接在悬浮窗上隐藏它。** 解锁后点击锁旁边的叉号。设置 > 悬浮窗 或托盘菜单可以让它重新显示。
- **新功能。** 更新后应用会像这样显示改动内容。
- 修复:Windows 短暂无法绘制悬浮窗时,应用不再关闭。

## 1.1.2

- **OBS 直播悬浮窗。** 设置 > OBS 和 Discord 提供一个 OBS 浏览器来源的链接,并带有背景滑块。
- **比赛未录制时提醒。** 如果比赛结束时没有回放,应用会提醒你一次。
- 应用中可以复制和粘贴了。

## 1.1.1

- 损坏的设置或比赛文件会从备份恢复,而不是被重置。
- 通知会以 Fortnite Chest Counter 的名义显示。
- 队友的数字在任何时区都能按时到达。

## 1.1.0

- **在线模式。** 使用本应用的队友会发送准确的宝箱数,让小队总数和奖品概率完整包含他们。
- 悬浮窗有了锁:解锁后可以移动悬浮窗并调整大小。
