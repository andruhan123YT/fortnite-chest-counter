# 更新紀錄

每個版本的簡短說明。應用程式在更新後會顯示一次新內容,也可以在
設定 > 關於 > 新功能 中再次查看。

## 1.1.6

- **地圖上的小隊寶箱。** 同樣使用本應用程式的隊友會顯示在地圖上,帶著他們搜過的每個寶箱,每人一種顏色。點擊一個即可看到是什麼時候、第幾個寶箱。為此,線上模式現在也會傳送你每個寶箱的時間、種類和位置,也包括以前的對戰。可在 設定 > 線上 中關閉。
- **抽到了什麼獎勵。** 每週獎勵和海盜商店通行權現在按名稱顯示,並附上時間和來源寶箱,對戰頁面和賽後通知中都有;對戰列表新增「獎勵」欄。隊友找到的獎勵標記為「小隊」,附近其他玩家獲得的標記為「不是你」。Gizmo 顯示為 Gizmo:重播沒有記錄是哪一個。
- **寶藏時刻。** 概覽顯示下一個或正在進行的寶藏時刻,附帶倒數和加成內容。開始前 15 分鐘會收到通知,進行中遊戲內疊加層會顯示「寶藏時刻」。在寶藏時刻中搜刮的寶箱會按加成計入海盜商店通行權機率。每一項都可在 設定 > 一般 中關閉。

## 1.1.5

- **自動安裝更新。** 有新版本時,應用程式會在 Fortnite 關閉後自動安裝。可在下方或 設定 > 關於 中關閉。
- **新增 16 種語言。** Fortnite 中的所有語言:德文、西班牙文(西班牙與拉丁美洲)、法文、義大利文、波蘭文、葡萄牙文(巴西)、土耳其文、印尼文、越南文、泰文、日文、韓文、中文(簡體與繁體)和阿拉伯文。應用程式會以 Windows 的語言啟動,可在 設定 > 一般 中切換。
- **全新設定。** 左側是分類,每個選項都有開關,每次變更都會立即儲存。
- **六種配色主題。** 預設仍是 Midnight;Graphite、Deep sea、Amethyst、OLED(純黑)和淺色的 Parchment 在 設定 > 一般 中。
- **在 Discord 中顯示寶箱。** Fortnite 執行時,你的 Discord 個人檔案會顯示總數、今天的寶箱和對戰計時,還有一個讓好友取得應用程式的按鈕。可在 設定 > OBS 和 Discord 中選擇顯示內容或關閉。
- **關於。** 版本、更新、說明和開源授權集中在一處。「複製應用程式資訊」會把回報問題所需的內容複製到剪貼簿。
- **可以變更對帳號的回答。** 設定 > 計數 會列出在這台電腦上玩過的其他帳號。誤標為你的或不是你的帳號可以改回來,其基數和獎品都會保留。
- 選單中新增 **「在 GitHub 上給星」** 連結。

## 1.1.4

- **俄文介面。** 可在第一次啟動時或在 設定 > 一般 中選擇語言。
- **一台電腦上的多個帳號。** 每個 Epic 帳號都有各自的總數,可在選單中切換。出現新帳號的重播時,應用程式會詢問是否是你的帳號。Epic 中的新名字會自動更新,不再需要輸入名字。
- **疊加層上的對戰計時。** 在「對戰中」旁邊顯示對戰自載入以來進行了多久。
- **疊加層會藏到其他視窗後面。** 用 Alt+Tab 離開 Fortnite 它就會消失,回來時又會出現。可在 設定 > 疊加層 中關閉。
- **遊戲結束後回到等待狀態。** 應用程式隨 Fortnite 啟動時,會在 Fortnite 關閉一分鐘後回到等待狀態。
- **挖出的寶箱也會計入。** 挖出時已經是開啟狀態的埋藏寶箱現在會計入。更新後會重新計算一次你的對戰。
- 修正:從清單中移除的對戰重新啟動後仍保持移除,網路慢時也能下載更新,設定中的核取方塊會立即生效。

## 1.1.3

- **排行榜。** 所有開啟線上模式使用本應用程式的人,依寶箱、最佳對戰和對戰場數排名,可看所有時間、本週或今天。點擊欄位可排序。在 設定 > 線上 中可以顯示為 Anonymous 而不是你的名字。
- **隨 Fortnite 啟動。** 登入 Windows 後,應用程式會安靜等待,Fortnite 啟動時在系統匣中開啟。可在 設定 > 一般 中改回隨 Windows 啟動。
- **直接在疊加層上隱藏它。** 解鎖後點擊鎖旁邊的叉號。設定 > 疊加層 或系統匣選單可以讓它重新顯示。
- **新功能。** 更新後應用程式會像這樣顯示變更內容。
- 修正:Windows 短暫無法繪製疊加層時,應用程式不再關閉。

## 1.1.2

- **OBS 直播疊加層。** 設定 > OBS 和 Discord 提供一個 OBS 瀏覽器來源的連結,並附有背景滑桿。
- **對戰未錄製時提醒。** 如果對戰結束時沒有重播,應用程式會提醒你一次。
- 應用程式中可以複製和貼上了。

## 1.1.1

- 損壞的設定或對戰檔案會從備份還原,而不是被重設。
- 通知會以 Fortnite Chest Counter 的名義顯示。
- 隊友的數字在任何時區都能準時送達。

## 1.1.0

- **線上模式。** 使用本應用程式的隊友會傳送準確的寶箱數,讓小隊總數和獎品機率完整包含他們。
- 疊加層有了鎖:解鎖後可以移動疊加層並調整大小。
